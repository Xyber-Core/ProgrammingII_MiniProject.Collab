# Security Policy

## Supported Versions

This project was developed as part of BACT 7601 Programming II Assessment 2. Security updates and fixes will be considered for the latest version of the project maintained in the group's GitHub repository.

| Version | Supported |
| ------- | --------- |
| Current version (main branch) | :white_check_mark: |
| Previous versions and older commits | :x: |

Only the latest maintained version is considered supported. Previous versions are retained for project history and reference but will not receive ongoing security updates.

## Reporting a Vulnerability

If you discover a potential security vulnerability in the Chemistry Inventory Management System, please report it privately to the project team through GitHub or the university's course communication channels.

Please include the following information in your report:

- A description of the potential vulnerability.
- The steps required to reproduce the issue.
- The affected file or part of the application, if known.
- Any relevant error messages or screenshots.

Please avoid reporting security vulnerabilities through public GitHub issues, as this could expose the problem before it has been addressed.

### What to Expect

The project team aims to acknowledge vulnerability reports within five working days while the project is actively maintained.

After reviewing the report:

- **If accepted:** The team will investigate the issue and, where appropriate, prepare a correction in the maintained version of the project.
- **If declined:** The reporter will be informed that the issue was reviewed and why it was not considered a security vulnerability.
- **If further investigation is needed:** The team will provide an update when more information becomes available.

As this is an academic group project rather than a commercially maintained application, security updates and responses are provided on a best-effort basis.
